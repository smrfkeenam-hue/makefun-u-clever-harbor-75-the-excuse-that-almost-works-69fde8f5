# The Excuse That Almost Works

One line a gamer texts the boss to skip work on GTA 6 launch week:

> IT took my laptop for the mandatory security patch and said I can't have it back until Thursday

18 words, one line, no trailing newline. The detail is boring and specific — IT holding the laptop for a patch — so a tired manager would almost believe it, and the laugh comes from the excuse's own logic: no laptop, no work, until Thursday.
